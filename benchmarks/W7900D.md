## Isolated warm A/B

The reference and candidate used independent containers/runtime directories and separate physical GPUs. Each path ran seed 43 as a cold warmup and seed 44 as the measured request. The warmup had `cached_nodes=[]`; the seed-44 measurement reused exactly six invariant nodes (`13`, `459:451` through `459:456` as applicable), with `prompt_suffix_length=0` and `warmup=false`. KSampler, VAE decode, and image save executed in the measured request.

| Metric | Reference | Fast candidate | Speedup |
|---|---:|---:|---:|
| End-to-end wall | 32,718.921 ms | 24,981.790 ms | 1.30971x |
| KSampler | 31,302.260 ms | 23,600.188 ms | 1.32636x |
| Step interval median | 1,247.652 ms | 935.705 ms | 1.333x |
| Step interval p95 | 1,250.575 ms | 964.122 ms | 1.297x |

The candidate selected the optimized attention path 832 times during the measured request with zero fallback. Capture recorded zero errors.

## Correctness scope

The composed extension passed the frozen micro oracles:

- Attention target T2I: cosine `0.9998848438`, max absolute error `0.00390625`.
- Attention target edit: cosine `0.9998809099`, max absolute error `0.001708984375`.
- RMSNorm/RoPE: four production cases passed with cosine at least `0.9999998212`, max absolute error at most `0.015625`, exact integer guards, and intact boundary guards.

The persisted end-to-end image comparison for RGBA 1024x1024 reported MAE `4.91042`, RMSE `14.46665`, cosine `0.994079`, PSNR `24.92344`, and identical-pixel ratio `0.134334`. This image comparison is observational, not the hard correctness gate; the frozen operator oracles are the hard gate.

## Standalone image reproduction

The image built from this repository (`sha256:3698286daa306924b4fbbc2e0e896355841cadf8e8fe17fab835f99663ab1018`) was run independently on physical GPU 6 using the same seed-43 warmup and seed-44 measurement sequence:

| Metric | Original fast candidate | Standalone image | Delta |
|---|---:|---:|---:|
| End-to-end wall | 24,981.790 ms | 25,064.687 ms | +0.33% |
| KSampler | 23,600.188 ms | 23,680.350 ms | +0.34% |

The standalone run selected the candidate attention path 1,664 times across the two requests with zero fallback. Its seed-44 decoded RGBA values are exactly equal to the original fast-candidate image (MAE `0`, RMSE `0`, identical-value fraction `1.0`). The PNG byte hashes differ because encoding metadata differs, not the pixels. Raw evidence is under `reproduced/`.
A second invocation in the same container first performed the scripted controlled restart, then measured **25,196.805 ms** wall and **23,742.351 ms** KSampler, again with 1,664 candidate calls, zero fallback, and pixel-identical RGBA output. This verifies that `scripts/benchmark.sh` is repeatable rather than dependent on a fresh container.
